Entry for the [Make the AI judge feel brave](https://make.fun/c/make-the-ai-judge-feel-brave-20261121-0302) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13, stdlib only) deterministically writes one short text — rain on glass, a humming kettle, lamplight — to `/output/entry.txt`, written to leave the AI judge reading it steadier, unhurried, and ready to move.
